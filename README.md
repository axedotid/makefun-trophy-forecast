# GTA VI Trophy Rarity Forecast

Trend-aware quantile forecaster for GTA VI PlayStation 5 trophy earn rates on Exophase.

## Approach

Fits a logit-linear trend to recent reads and projects it forward with tier-calibrated spread. Accounts for Exophase refresh cycles and player growth.

## Run

```bash
npx tsx main.ts
```
